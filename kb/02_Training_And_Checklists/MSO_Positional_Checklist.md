# MSO Positional Checklist

**Last Reviewed:** 2026-08-13  
**Tags:** `#checklist` `#mso`  
**Source:** Training template + Aircrew Aid themes (unclassified paraphrase)

## Pre-mission
- [ ] Review brief: radar status, EMCON plan, freqs (≤16 enabled for TPS-75 EMCON planning)
- [ ] Confirm crew positions / intercom
- [ ] Know vul window and bullseye

## Scope / systems
- [ ] Open BC3 → set **Scope Profile** next
- [ ] Bullseye / reference set
- [ ] Verify TPS-75 feed healthy (range/alt picture makes sense vs brief)
- [ ] Note EP/EA status with EPT — translate impact to WD/ABM

## During vul
- [ ] Monitor track continuity / dropouts
- [ ] Call out radar degradations that change the picture
- [ ] Support WD/ABM requests (filters, focus, troubleshooting)

## Debrief
- [ ] Capture systems DFPs/LPs
- [ ] Feed MQF/systems misses into personal flashcards
