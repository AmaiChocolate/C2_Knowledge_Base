# WD Positional Checklist

**Last Reviewed:** 2026-08-13  
**Tags:** `#checklist` `#wd`

## Pre-mission
- [ ] SPINS / ROE / ID matrix highlights
- [ ] BMA, CAP, safe passages, tanker tracks
- [ ] Contracts with MC/ABM (lanes, commit authority, handovers)
- [ ] Frequencies primary/secondary

## Scope setup
- [ ] Overlays loaded; bullseye confirmed
- [ ] Symbology / altitude bands usable
- [ ] Know radar feed health from MSO

## Vul execution
- [ ] Fighter check-in + Alpha Check
- [ ] Picture cadence (groups → waves → label → leading edge → alt → fill-ins)
- [ ] Commit criteria met before commit language
- [ ] Sort / targeting clarity; leaker awareness
- [ ] Tanker/HVAA protect cues

## Debrief
- [ ] Missed groups, late commits, bad BRAA — timeline if using sim logger
