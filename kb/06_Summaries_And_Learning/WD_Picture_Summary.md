## Call order
Callsign → total groups → (LEADING EDGE) label + dimensions → amplifying remarks (WEIGHTED / TRACK) → each group: name, BULLSEYE, altitude, declaration, fill-ins → follow-on waves

## Labels
- **AZIMUTH / RANGE** — two groups: wider than deep / deeper than wide
- **WALL** — 3+ abreast, depth ≤ 5 nm
- **LADDER** — 3+ in range/depth
- **CHAMPAGNE / VIC / BOX** — depth > 5 nm; geometry-specific (see full note)
- Altitude to the nearest thousand (not HIGH/LOW); `HEAVY` = 3+ contacts in a group; lopsided = `WEIGHTED`

## Grouping
Contacts within ~**3 NM** → same group (sim clusterer default)
